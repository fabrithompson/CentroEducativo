## Instrucciones de uso

Cada intervención que involucre **cambios en el repositorio** con asistencia de IA debe
registrarse como una fila nueva en la tabla, **sin excepción y en el mismo commit que el cambio**.

- **Nº:** correlativo, nunca se reutiliza ni se reordena.
- **Problema:** qué se necesitaba resolver, en una frase.
- **Prompt utilizado:** el prompt real, resumido si excede las 3 líneas (indicar "[resumido]").
- **Herramienta de IA:** nombre y modelo (ej. Claude Code — Opus 5, ChatGPT — GPT-5, Copilot).
- **Respuesta de IA:** qué produjo concretamente (archivos, endpoints, esquema, análisis).
- **¿Funcionó?:** `Sí` / `Parcialmente` / `No`.
- **Modificaciones realizadas:** qué tuvo que corregir o ajustar el equipo a mano.
- **Resultado:** `Correcto` (quedó en el proyecto) o `Reemplazado` (se descartó o se rehízo).

> Si la IA se usó sólo para consultar o explicar, sin producir cambios, no corresponde registrar.
